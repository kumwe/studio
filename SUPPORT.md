# Support

Kumwe Studio is currently a foundation programme, not a supported production product.

- Use a **bug report** for reproducible behaviour that contradicts a declared contract.
- Use a **proposal** for a new contract, capability, package, integration, or design change.
- Use repository discussions, when enabled, for implementation questions that do not describe a defect.
- Use GitHub's private vulnerability reporting for security concerns.

Before asking for help, include the commit or package version, host capabilities, relevant artifacts with secrets removed, expected behaviour, observed behaviour, and the smallest reproducible sequence of commands.

The roadmap expresses intent, not a service-level agreement. Gate status is recorded only in `docs/roadmap/STATUS.md`.
