Ship Studio as a host-neutral, self-contained ESM browser distribution with a stable bootstrap API, integrity
manifest, archive-local deployment documentation, the complete recursive schema closure, a framework-neutral
PHP reference boundary, notices, license texts, and no production Node.js requirement. Govern the exact same
prebuilt module inside the npm package and deterministic versioned beta/RC/stable release archives.

Publish the closed browser-asset manifest schema so non-npm and PHP hosts can validate the files they deploy.
The manifest also publishes the exact same-origin CSP header template, fresh style-nonce requirements, and the
nonce/hash-free inert JSON configuration rule; the PHP reference consumes that policy without `unsafe-*`
sources and the browser lane proves the complete hosted round trip under it.

Bind each host-emitted deployment to `studio-assets.json.release`. The browser module compiles the same release
identity and rejects cross-release configuration before DOM selection, runtime construction, or network access;
the PHP reference copies and verifies the manifest release at emission time.
